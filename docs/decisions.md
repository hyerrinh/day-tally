# 결정 기록

> 기능명세서·DB 설계서 V1 이후 만들면서 바뀌거나 확정된 결정을 남긴다.
> 결정이 바뀌면 이 문서에 먼저 추가하고, 관련 문서(기능명세서, DB 설계서, ROADMAP)에 반영한다.
